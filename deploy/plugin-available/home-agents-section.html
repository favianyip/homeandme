Claude Code

Add the plugin with these two lines in Claude Code.

/plugin marketplace add __REPO_OWNER__/homeandme-mcp
/plugin install homeandme@homeandme

Then ask it about Home & Me. It can explain the service, give you the request link, and check where your design stands.

Other assistants

The plugin is an MCP plugin. In any assistant that takes MCP plugins, run the one file dist/server.mjs with Node 18 or newer.
