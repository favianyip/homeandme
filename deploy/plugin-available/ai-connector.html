A Home & Me plugin for AI assistants (an MCP connector) is available: install it from here. It reads the public facts on this site, gives the link where you start your own design request, and reads where your design stands from your own private status link. It sends nothing about you anywhere: you send your request yourself.

  • Claude Code: /plugin marketplace add __REPO_OWNER__/homeandme-mcp, then /plugin install homeandme@homeandme.
  • Claude Desktop and other MCP clients: run the one file dist/server.mjs with Node.js 18 or newer, over stdio.
